편집기로 돌아가기

선택하고 수정하기

화면에서 선택을 켠 상태로 사진이나 문구를 누르면 오른쪽에서 편집할 수 있습니다. 사진 업로드는 JPEG·PNG·WebP를 지원하며 최대 12MB입니다. 큰 사진은 브라우저에서 축소됩니다. PC·모바일 탭은 미리보기 크기를 바꿉니다. 글자 크기 변경은 선택한 화면 크기에만 적용되고, 문구·사진·색·정렬은 공통 적용됩니다.

배치와 의견

왼쪽에서 섹션을 선택하고 순서를 바꾸거나 숨길 수 있습니다. 메인 화면과 상담 영역은 숨길 수 없습니다. 세부 요소의 자유 드래그 배치는 지원하지 않습니다. 수정 의견은 선택한 요소에 연결되어 저장됩니다. 숨긴 섹션은 다시 표시한 뒤 편집해주세요.

저장과 백업

변경사항은 이 기기·이 브라우저의 IndexedDB에 자동 저장됩니다. 저장 실패 시 상단에 표시됩니다. 시크릿 모드, 브라우저 데이터 삭제, 주소나 브라우저 변경 시 초안이 사라질 수 있으므로 변경 파일 내보내기로 JSON 백업을 내려받으세요. 파일을 이 채팅에 첨부하면 변경 내용과 의견을 확인하여 배포할 수 있습니다. 다른 기기에서는 이 JSON을 불러오면 됩니다. 개인정보나 비밀번호는 적지 마세요.

공개 홈페이지와의 관계

여기는 로그인된 서버 관리자 페이지가 아닌 로컬 편집 도구입니다. 주소를 아는 사람은 도구를 열 수 있지만 각자의 브라우저에만 저장되며 다른 사람의 초안을 볼 수 없습니다. 업로드 사진도 서버로 전송하지 않습니다. 발행 기능·인증·파일 업로드 서버는 없습니다. 저장이나 내보내기만으로 공개 사이트가 변경되지 않습니다.

배포용 HTML

배포용 HTML은 수정된 index.html 파일을 내려받습니다. 기존 홈페이지 폴더에 있는 styles.css와 최신 site.js가 함께 있어야 합니다. 사진은 HTML 안에 포함됩니다. 파일을 검토한 다음 기존 GitHub 저장소에 반영해야 공개 사이트에 적용됩니다. 내보내는 파일에는 편집 의견이 포함되지 않습니다. 소셜 공유 대표 사진·설명은 이 편집기로 자동 변경되지 않습니다.
