SORI vocal studio

녹음으로 확인하고 결과물로 남기는 1:1 개인 맞춤 스튜디오

보컬 부스와 디렉 컨트롤룸을 갖춘 SORI vocal studio입니다. 가녹음부터 실제 녹음, 보정, 믹싱, 전후 테스트까지 현재 목소리를 객관적으로 확인하고 결과물로 남기는 흐름으로 진행합니다.

인스타그램
01 처음이어도 부담 없이

짧은 테스트 녹음으로 현재 상태를 먼저 확인합니다.

02 디렉과 녹음을 함께

컨트롤룸에서 박자, 음정, 톤을 바로 듣고 조정합니다.

03 한 달, 한 곡 완성

정규 커리큘럼은 1곡 커버 완성을 기준으로 진행합니다.

Studio interior

소리를 편안하게 확인하는 실내 구성

Vocal booth

보컬 부스

짧은 테스트 녹음부터 실제 커버 녹음까지, 마이크 앞에서 현재 목소리의 톤과 호흡을 정확히 확인하는 공간입니다.

Control room

디렉을 보는 컨트롤룸

녹음 중 박자, 음정, 감정선, 발음 디렉을 바로 주고받으며 결과물을 함께 만들어가는 공간입니다.

Consulting room

방향을 함께 정하는 상담 공간

좋은 결과물을 위해 커리큘럼을 소개하고, 현재 목표와 준비 상태에 맞춰 작업 방향을 함께 설정합니다.

Studio equipment

좋은 장비는 목소리를 더 정확하게 판단하게 합니다

녹음부터 모니터링, 보정, 믹싱과 마스터링까지 각 단계에 맞는 장비와 소프트웨어를 사용합니다. 화려한 이름보다 결과의 차이를 직접 듣고 선택할 수 있는 작업 환경을 중요하게 생각합니다.

Monitoring

녹음과 믹스를 정확하게 확인

Focal Shape 50과 IsoAcoustics 스탠드로 밸런스를 확인하고, 서로 다른 성향의 두 헤드폰으로 결과를 교차 점검합니다.

  • Focal Shape 50
  • IsoAcoustics
  • Sony Monitor · Audeze MM-100
03

Production system

  • Mac Studio · M4 Max
  • 64GB Memory
  • Cubase Pro 15
